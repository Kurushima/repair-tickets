# Учёт заявок на ремонт компьютеров

API на Go для создания заявок, смены статусов и просмотра истории. Заявки хранятся в PostgreSQL, карточки кешируются в KeyDB. Изменения статусов отправляются через RabbitMQ, а отдельный обработчик сохраняет их в историю.

## Запуск

При запущенном Docker из папки проекта выполняется команда:

```sh
docker compose up -d --build --wait
```

API доступен по адресу `http://127.0.0.1:18080`. Для проверки используется запрос `GET /health` в Postman. Сервер возвращает статус `200 OK` и тело `ok`.

## Запросы

| Метод и путь | Что делает |
|---|---|
| `GET /health` | Проверяет запуск API |
| `POST /tickets` | Создаёт заявку с телом `{"description":"Ноутбук не включается"}` |
| `GET /tickets/{id}` | Возвращает карточку заявки |
| `PATCH /tickets/{id}/status` | Меняет статус. Пример тела `{"status":"in_progress"}` |
| `GET /tickets/{id}/history` | Возвращает историю смены статусов |

Вместо `{id}` подставляется номер из ответа `POST /tickets`. Тело запросов `POST` и `PATCH` передаётся в формате JSON. Статусы идут по порядку `new → in_progress → closed`. История обновляется после обработки события.
